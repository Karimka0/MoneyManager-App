# Приложение для управления финансами

Многофункциональное десктопное приложение на C++ и Qt для ведения личного бюджета, анализа расходов и доходов, а также визуализации финансовой статистики.

## 🚀 Возможности

- Ведение списка транзакций: доходы и расходы
- Указание категорий, дат и описаний для каждой операции
- Визуализация финансовых данных с помощью графиков (QCustomPlot)
- Локальное хранение данных на базе SQLite
- Удобный и интуитивно понятный графический интерфейс (GUI)

## 🛠️ Стек технологий

- **C++**
- **Qt (Widgets, Qt Designer)**
- **SQLite**
- **QCustomPlot** — библиотека для отрисовки графиков


## 🧩 Архитектура

- `main.cpp` — точка входа
- `MainWindow` — основной UI-класс
- `Transaction` — структура данных для хранения операций
- `DatabaseManager` — класс для взаимодействия с SQLite
- `PlotWidget` — виджет для построения графиков

## ⚙️ Установка и запуск

### Зависимости

- Qt 5 или 6 (установите через [Qt Installer](https://www.qt.io/download))
- CMake (или Qt Creator IDE)
